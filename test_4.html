Documentation

La bibliothèque JavaScript Web-Sciences permet de configurer une interface interactive pour des expériences de physique. En définissant quelques variables, vous pouvez personnaliser les mesures, les commandes et les graphiques.

Structure du Code JavaScript

1. Mode de fonctionnement (mode)

La variable mode détermine le type d'interface utilisé :

  • "commande" : Interface avec des boutons pour envoyer des commandes à la carte Arduino.
  • "point" : Interface pour effectuer une mesure ponctuelle (par exemple : tension, distance).
  • "temporel" : Interface pour effectuer une acquisition en fonction du temps.

2. Commandes à envoyer (commandes)

La variable commandes est un tableau d'objets contenant les commandes à envoyer à la carte Arduino :

var commandes = [
    {texte_bouton: "Charge", arduino: "charge"}, 
    {texte_bouton: "Décharge", arduino: "decharge"}
];

3. Séries de données (series)

La variable series est un tableau d'objets définissant les grandeurs et leurs unités retournées par la carte Arduino :

var series = [
    {grandeur: "Uc", unite: "V"}, 
    {grandeur: "E", unite: "V"}
];

Note : En mode temporel, la première série est toujours le temps. Il n'est pas nécessaire de l'ajouter dans series.

4. Axes du graphique (axes)

La variable axes détermine le graphique affiché :

  • Mode temporel : L'abscisse est le temps, et les ordonnées correspondent aux séries définies dans series.
  • Mode point : L'abscisse est la grandeur définie par l'utilisateur (exemple : distance en cm), et les ordonnées correspondent aux séries définies dans series.
  • Mode commande : Pas de graphique affiché.

Utilisation Avancée

1. Insérer le code JavaScript dans une cellule Jupyter avec web_sciences.py

La bibliothèque web_sciences.py permet d'insérer le code JavaScript dans une cellule Jupyter. Suivez ces étapes :

  1. Placez le fichier web_sciences.py dans le même dossier que votre notebook.
  2. Importez la bibliothèque avec : 
    from web_sciences import insere_code
  3. Créez une chaîne contenant votre code JavaScript et insérez-la dans une cellule : 
    insere_code(my_init)
  4. Exécutez la cellule pour afficher l'interface.

2. Insérer le code JavaScript dans un fichier HTML avec insere_code.py

Pour créer un fichier HTML autonome, utilisez insere_code.py :

  1. Placez insere_code.py et web_sciences_complet.html dans le même dossier.
  2. Copiez votre code JavaScript dans insere_code.py.
  3. Exécutez le script pour générer un fichier HTML prêt à l'emploi.

Exemple :

# insere_code.py
from web_sciences import creer_html

my_init = '''
var mode = "point";
var series = [
    {grandeur: "Distance", unite: "cm"}, 
    {grandeur: "Temps", unite: "s"}
];
'''

creer_html(my_init, "output.html")
