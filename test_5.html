Documentation complète du JavaScript

1. Commandes

Les commandes permettent de définir les boutons disponibles pour interagir avec la carte Arduino. Chaque commande associe un texte affiché à un message envoyé à la carte.

var commandes = [
    {texte_bouton: "Charge", arduino: "charge"},
    {texte_bouton: "Décharge", arduino: "decharge"}
];

2. Séries

Les séries définissent les données mesurées et leur unité associée.

var series = [
    {grandeur: "Uc", unite: "V"},
    {grandeur: "E", unite: "V"}
];

Remarque : En mode temporel, la première série renvoyée est toujours le temps. Il n’est pas nécessaire de la préciser dans series.

3. Axes

Les axes définissent le graphique affiché selon le mode sélectionné :

  • Mode temporel : L’abscisse est toujours le temps. Les ordonnées sont les séries définies.
  • Mode point : L’abscisse est la grandeur spécifiée par l’utilisateur. Les ordonnées sont les séries définies.
  • Mode commande : Aucun graphique n’est affiché.

4. Insérer le code dans un notebook Jupyter

Pour utiliser web_sciences.py dans un notebook Jupyter :

  1. Importez la bibliothèque : from web_sciences import WebSciences
  2. Créez une variable contenant le code JavaScript.
  3. Utilisez la méthode affiche pour insérer l’interface.
from web_sciences import WebSciences

my_init = """
var mode = "point";
var commandes = [{texte_bouton: "Mesure", arduino: "vas_y"}];
var series = [{grandeur: "T", unite: "°C"}];
"""

interface = WebSciences(my_init)
interface.affiche()

5. Insérer le code dans un fichier HTML

Pour utiliser insere_code.py et web_sciences_complet.html :

  1. Copiez le code JavaScript dans le fichier insere_code.py.
  2. Exécutez insere_code.py pour générer un fichier HTML.
  3. Ouvrez ce fichier dans un navigateur compatible pour interagir avec la carte Arduino.
python insere_code.py

Remarque : Pour utiliser un tableur, ajoutez tableur = true; au code JavaScript. Les données seront copiées dans le presse-papiers au format compatible.
