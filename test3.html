Web-Sciences - Documentation JavaScript

Documentation JavaScript

La bibliothèque JavaScript Web-Sciences permet de configurer une interface interactive pour des expériences de physique. En définissant quelques variables, vous pouvez personnaliser les mesures, les commandes et les graphiques.

Structure du Code JavaScript

1. Mode de fonctionnement (mode)

  • Définit la manière dont les données sont envoyées par la carte Arduino.
  • Valeurs possibles :
    • "point" : Envoie une seule mesure sur demande.
    • "temporel" : Envoie un flux continu de mesures.
    • "commande" : Exécute des actions spécifiques basées sur l'interaction utilisateur.
var mode = "commande";

2. Commandes à envoyer (commandes)

  • Liste d'objets définissant les boutons de commande.
  • Chaque objet contient :
    • texte_bouton : texte affiché sur le bouton.
    • arduino : commande envoyée à la carte Arduino.
var commandes = [
    {texte_bouton: "Charge", arduino: "charge"}, 
    {texte_bouton: "Décharge", arduino: "decharge"}
];

3. Séries de données (series)

  • Définit les grandeurs mesurées, leur nom et leur unité.
  • Chaque objet contient :
    • grandeur : nom de la grandeur mesurée.
    • unite : unité correspondante.
  • Remarque : En mode temporel, la première série renvoyée par la carte est toujours le temps. Il n'est pas nécessaire de la préciser dans la variable series.
var series = [
    {grandeur: "Uc", unite: "V"}, 
    {grandeur: "E", unite: "V"}
];

4. Axes du graphique (axes)

  • Configure les axes pour le graphique.
  • Chaque axe est défini par :
    • nom : label de l'axe.
    • unite : unité correspondante.
  • Remarques spécifiques par mode :
    • Mode temporel :
      • L'abscisse est toujours le temps.
      • Les grandeurs en ordonnées sont les séries définies dans la variable series.
    • Mode point :
      • L'abscisse correspond toujours à la grandeur saisie par l'utilisateur (ex. : d (cm)).
      • Les grandeurs en ordonnées sont celles définies dans series.
    • Mode commande : Aucun graphique n'est généré.
var axes = [
    {nom: "Temps", unite: "s"}, 
    {nom: "Uc", unite: "V"}
];

Exemples Complets

Commande avec boutons

var mode = "commande";
var commandes = [
    {texte_bouton: "Charge", arduino: "charge"}, 
    {texte_bouton: "Décharge", arduino: "decharge"}
];
var series = [
    {grandeur: "Uc", unite: "V"}, 
    {grandeur: "E", unite: "V"}
];

Mesure Temporelle

var mode = "temporel";
var commandes = [{texte_bouton: "Démarrer", arduino: "start"}];
var series = [{grandeur: "Température", unite: "°C"}];
var axes = [
    {nom: "Temps", unite: "s"}, 
    {nom: "Température", unite: "°C"}
];
